# TVORIBOX — дизайн-система

Интернет-магазин наборов для творчества и материалов для хобби. Доставка по Казахстану. Макеты сделаны в Google Stitch (режим Web). Фронтенд будет на React (Vite). Этот файл согласован с `docs/architecture.md`; при расхождении главным считается `architecture.md`.

## 1. Стиль

- **3 слова:** яркий, тёплый, дружелюбный
- **Главный цвет:** оранжевый `#F28C28`
- **Настроение:** светлый фон, много воздуха, крупные карточки с фото, оранжевые кнопки «В корзину»
- **Примеры, которые вдохновили (идея, не копия):**
  1. https://example-1 — что понравилось: …
  2. https://example-2 — что понравилось: …

## 2. Цвета

| Роль | HEX | Где используется |
|---|---|---|
| Primary | `#F28C28` | главные кнопки, цена, акценты |
| Secondary | `#FBBF24` | бейджи, подсветка |
| Tertiary | `#0D9488` | иконки категорий, ссылки |
| Neutral | `#1F2937` | заголовки, тёмные кнопки, подвал |
| Фон страницы | `#FFFFFF` | основной фон |
| Фон карточек и блоков | `#F3F5FA` | карточки, боковая панель |
| Основной текст | `#3E2A1E` | абзацы, описания |
| Рамки | `#D9DEE8` | поля ввода, карточки |
| Ошибка | `#DC2626` | ошибки форм, статус «Отменён» |

Правила:
- Главный цвет только для кнопок и ключевых акцентов, фон остаётся светлым.
- Текст всегда тёмный на светлом, без светло-серого на белом.

## 3. Статусы заказа

Шесть статусов из `architecture.md`. Оплаты в MVP нет, статуса «Оплачен» нет.

| Код в БД | Подпись (RU) | Цвет плашки | HEX |

Текст на плашках: тёмный на жёлтом, белый на остальных.

## 4. Шрифты

Семейство: **Plus Jakarta Sans** (Google Fonts). Поддерживает кириллицу, для казахских букв (ә, ғ, қ, ң, ө, ұ, ү, һ, і) проверить в браузере; запасной шрифт `Arial, sans-serif`.

| Назначение | Размер | Начертание |
|---|---|---|
| H1 (главный блок) | 44–56 px | Bold |
| H2 (секции) | 28–32 px | Bold |
| H3 (карточка) | 18–20 px | SemiBold |
| Основной текст | 16 px | Regular |
| Подписи и метки | 12–14 px | Medium |

## 5. Кнопки

| Вид | Применение |
|---|---|
| **Primary** (`#F28C28`) | главное действие: «В корзину», «Оформить заказ», «Смотреть каталог» |
| **Secondary** | второстепенное: «Подробнее», «Назад» |
| **Inverted** (`#1F2937`, белый текст) | «Войти», «Выйти» |
| **Outlined** | нейтральное: «Продолжить покупки» |
| **Icon** (круглые) | редактировать, удалить (красная) |

Скругление 8–12 px, высота 40–48 px. На странице одна главная Primary-кнопка.

## 6. Карточки

**Карточка товара:** фото, название (`nameRu` или `nameKk` по выбранному языку), короткое описание, цена, остаток, кнопка «В корзину» на всю ширину. Фон `#F3F5FA`, скругление 12–16 px, отступ 16 px. Если остаток 0: кнопка неактивна, надпись «Нет в наличии».

**Карточка категории:** иконка (Tertiary) и название (`nameRu` или `nameKk`).

**Блок доставки и оплаты:** иконка, заголовок, 1–2 строки текста.

## 7. Поля ввода и навигация

- Поля форм и поиск: белый фон, рамка `#D9DEE8` 1 px, скругление 8–12 px; при фокусе рамка Primary.
- Метка над полем, ошибка красным под полем.
- Поиск в каталоге: одна строка, параметр `search`.

## 8. Отступы и сетка

- База 8 px (8, 16, 24, 32, 48).
- Контейнер до 1200 px по центру.
- Каталог: 3 колонки на десктопе, 2 на планшете, 1 на телефоне.
- Между секциями 64–80 px.

## 9. Общие элементы на всех страницах

- **Шапка:** логотип TVORIBOX, меню (Каталог, Доставка, Контакты), **переключатель языка RU | KK**, корзина, «Войти» или профиль.
- **Подвал:** логотип, разделы, контакты (телефон, email, адрес).
- Весь интерфейс на двух языках: русский и казахский (US4). Тексты товаров и категорий берутся из `nameRu` и `nameKk`. Макеты Stitch сделаны на русском.

## 11. Правила бизнеса, которые видны в дизайне

- **Оплата только при получении** (наличными или переводом). Онлайн-оплаты картой нет, она после MVP (R15).
- **Самовывоз только в Алматы** (R7). Курьер: Алматы и Астана.
- Заказ можно оформить гостем (имя и телефон) или клиентом с кабинетом.
- Каталог умеет только поиск, фильтр по категории и страницы. Сортировки и фильтра по цене нет, их нет в API.

## 12. Чего нет в MVP (не добавлять в дизайн)

- онлайн-оплата картой
- «Избранное»
- отзывы и рейтинг
- чат с продавцом
- скидки и старые цены
- сортировка и фильтр по цене

## 13. Инструкция для ИИ-агента (фронтенд)

- React (Vite). Цвета, размеры и отступы вынести в CSS-переменные из разделов 2, 3, 4 и 8.
- Компоненты: `Header` (с переключателем RU | KK), `Footer`, `Button` (primary / secondary / inverted / outlined), `ProductCard`, `CategoryCard`, `Input`, `StatusBadge` (6 статусов из раздела 3).
- HTML из Stitch не копировать, ориентироваться на скриншоты в `docs/screens/` и на этот файл.
